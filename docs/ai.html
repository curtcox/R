Ask for an R change

Open Ask, describe a source or input change and choose a model. Paste handoff works without an account: prepare/copy the prompt, use your preferred chat and paste its JSON reply. Connected providers require explicit destination consent and spending caps; caps start at zero. The canonical editor connects through the separate AI host. The recovery copy uses keys in memory and disconnects on reload. No key is stored on the editor origin.

Review the text diff before Accept change. Acceptance and undo stop current execution, retain the document's Auto-run preference and wait for Run. Changing the Auto-run checkbox does not bypass that hold. Editing continues through normal drafts and share links. Navigation invalidates old proposals. An incoming link never calls a model or downloads model weights.

The gallery keeps ordinary text/tag filtering and offers optional model suggestions from sample metadata. Model suggestions do not open programs or run code on their own.

Compare models evaluates the 25 synthetic cases in the suite. Every good and bad reference is checked by real webR 0.6.0 / R 4.6.0 in a fresh opaque sandbox. Output is limited to 64 KiB, setup to 30 seconds, and execution to the existing five-second auto-run limit. Input tests include the editor's documented echo behavior. Your own saved cases stay local and are excluded from exports by default.
